# Bar Manager

A small macOS menu bar app that folds icons you rarely use behind a chevron, the way Hidden Bar
and Bartender do. Single Swift file, no dependencies.

## How it works

The app adds one status item, a chevron. Everything to the left of it is the hidden section.
When collapsed, the item stretches to the width of the screen, which pushes the icons left of it
off the visible menu bar. macOS stops drawing a status item once it no longer fits, so while
collapsed the chevron is drawn by a small borderless window floating over the spot where the item
ends. Clicking that window expands the item again, which shrinks it back to a normal status item
and the icons return. macOS keeps the position of the item itself, so the arrangement survives
restarts.

The floating chevron follows the main screen's menu bar and hides when the menu bar does (full
screen apps). To ⌘-drag the chevron somewhere else, expand it first so it is a real status item.

## Build and install

```sh
./build.sh --install
```

This compiles `sources/main.swift` with `swiftc` (Xcode Command Line Tools), bundles it as
`~/Applications/Bar Manager.app`, and launches it. Plain `./build.sh` only builds into `build/`.
The icon is generated by `make-icon.swift` the first time, or on demand with `swift make-icon.swift`.

## Use

- Hold ⌘ and drag an icon to the left of the chevron to hide it, or to the right to show it again.
- Click the chevron to show or hide the section. It hides again on its own after a delay.
- Right-click the chevron for options: the auto-hide delay (never, 5s, 10s, 30s, 1 min),
  Launch at Login, help, and Quit.
- ⌘-drag the chevron to move the hidden section.

System items on the far right (Wi‑Fi, battery, clock, Control Center) cannot be hidden, since macOS
pins them.

## Settings

Stored in `defaults` under `com.kobe.bar-manager`: `collapsed`, `auto-collapse-seconds`, and the
`NSStatusItem Preferred Position` key macOS writes for the chevron. To start over:

```sh
defaults delete com.kobe.bar-manager
```
